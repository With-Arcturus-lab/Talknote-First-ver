# TalkNote

TalkNoteは、会話が難しい場面で「伝えたいこと」「体調」「予定」「聞きたいことと回答」「日記」を記録しながら使える、コミュニケーション補助アプリです。

ALSなどにより発話が難しくなった方が、通院、訪問看護、リハビリ、家族とのやりとりの中で、スマートフォンの画面を相手に見せながら意思を伝えられることを目指しています。

## 主な機能

- 伝えたい文章を大きく表示
- よく使う定型文の追加、編集、削除
- 体調を5段階で記録
- 体調項目や「当てはまること」の編集
- カレンダーで予定、伝えたこと、Q&A、日記を管理
- 聞きたいことと回答を後から検索
- その日の記録から振り返り文を作成
- ローカル保存データのバックアップ書き出し、読み込み
- テーマ切り替え、文字サイズ、高コントラスト設定

## データの保存について

入力した内容は、利用している端末のブラウザ内に保存されます。

GitHub Pagesで公開した場合でも、通常の利用で入力した記録がGitHubや開発者のサーバーに送信されることはありません。ただし、ブラウザのデータ削除、端末変更、故障などで記録が消える可能性があります。必要に応じて、設定画面からバックアップを書き出してください。

バックアップファイルには個人的な記録が含まれるため、保存先や共有相手には注意してください。

## 注意事項

このアプリは、医療上の診断、治療方針の決定、緊急時の判断を行うものではありません。

体調の急変や緊急時は、主治医、訪問看護、救急などの指示を優先してください。

## 使い方

`index.html` をブラウザで開くと利用できます。

GitHub Pagesで公開する場合は、このリポジトリの `index.html`、`styles.css`、`app.js` をそのまま公開対象にします。

## 公開時の注意

GitHub Pagesで公開すると、アプリ画面自体はインターネット上に公開されます。個人情報、実際の記録データ、バックアップファイル、患者さんの情報をリポジトリにアップロードしないでください。
